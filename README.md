# QuikConverter - Universal Unit Converter

A high-performance, privacy-focused conversion tool designed for professionals and students. Built with pure HTML5, CSS3, and JavaScript.

## Features

- *Multiple Categories*: Common, Engineering, Finance, Developer tools
- *Real-time Conversions*: Instant calculations as you type
- *Responsive Design*: Works on desktop and mobile
- *Dark Theme*: Easy on the eyes
- *Copy to Clipboard*: One-click result copying
- *Visual Context*: Helpful comparisons and facts

## Categories Included

- *Common*: Length, Weight, Temperature, Volume, Area
- *Engineering*: Velocity, Acceleration, Density, Torque
- *Finance*: Currency, Salary, Crypto, Market Cap
- *Developer*: Base Converter, Color Converter, JSON Formatter, Epoch Time

## Technologies Used

- HTML5
- CSS3 (CSS Grid, Flexbox, CSS Variables)
- Vanilla JavaScript
- Google Material Icons
- Google Fonts (Montserrat, Oswald)
